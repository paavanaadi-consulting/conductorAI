# Movie Recommendation Platform – AI/Data Engineering Project

## Project Overview

Build a **scalable movie recommendation platform** that demonstrates modern **microservices architecture, CI/CD pipelines, data engineering pipelines, and machine learning workflows**.

The system should:

* Serve movie recommendations through **Java microservices**
* Process and migrate data from operational databases into a **data warehouse**
* Implement a **Medallion Architecture (Bronze, Silver, Gold)**
* Train and serve a **machine learning recommendation model**
* Provide an **AI chatbot interface** for user interaction

The project should demonstrate production-grade architecture suitable for enterprise systems.

---

# 1. High-Level Architecture

System layers:

1. **Frontend**

   * Web or simple UI
   * Allows users to search movies and get recommendations
   * Chatbot interaction

2. **Java Microservices Layer**

   * Movie Service
   * Recommendation Service
   * User Service
   * Chatbot Service
   * API Gateway

3. **Operational Database**

   * PostgreSQL / MySQL
   * Stores user activity, ratings, and movie metadata

4. **Data Engineering Layer**

   * PySpark pipelines
   * Data ingestion and transformation
   * Medallion architecture implementation

5. **Data Warehouse**

   * Snowflake / BigQuery / Redshift / Delta Lake

6. **ML Layer**

   * Model training in Silver layer
   * Recommendation engine

7. **AI Chatbot Layer**

   * Chatbot uses Gold layer data

---

# 4. Medallion Architecture

Implement **Bronze → Silver → Gold layers**.

## Bronze Layer (Raw Data)

Data ingestion from:

* user_activity table
* movie_metadata table
* ratings table

Store as:

* Parquet / Delta tables

Characteristics:

* Raw data
* No transformations
* Append-only

---

## Silver Layer (Cleaned + Feature Engineering)

Tasks:

1. Data cleaning
2. Handling null values
3. Deduplication
4. Feature engineering

Example features:

* average_movie_rating
* user_genre_preference
* movie_popularity_score

### ML Model Training

Train recommendation models such as:

* Collaborative Filtering
* Matrix Factorization
* ALS (Alternating Least Squares)

Use:

* PySpark MLlib

Output:

* Trained recommendation model
* User embedding vectors
* Movie embedding vectors

Artifacts stored in:

* Model registry or object storage

---

## Gold Layer (Business Ready Data)

Curated datasets used by applications.

Examples:

Tables:

* user_recommendations
* top_movies_by_genre
* trending_movies

These tables power:

* Recommendation Service
* Chatbot Service

---
